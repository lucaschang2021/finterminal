# Support

FinTerminal is an early-stage open-source research project. Support is community-oriented and best-effort; there is currently no commercial SLA or guaranteed response time.

## Where to ask

- **Bug:** open a GitHub issue using the bug-report template.
- **Feature or integration idea:** open a feature request.
- **Security vulnerability:** follow `SECURITY.md` instead of posting publicly.
- **General usage question:** open an issue with enough context for another user to reproduce your setup.

## What to include

Please provide the FinTerminal version or commit, operating system, relevant component (MCP service or desktop), reproduction steps, expected and actual behavior, and sanitized logs where useful.

Never post API keys, credentials, brokerage/account identifiers, private financial documents, or sensitive local-file contents.

## Scope

Maintainers will prioritize reproducible defects, security issues, installation blockers, data-integrity problems, and well-scoped contributions. Questions that depend on proprietary data providers, private model accounts, or undocumented third-party behavior may require the reporter to reproduce the issue independently.

FinTerminal does not provide investment, trading, brokerage, custody, legal, tax, or compliance support.
