# FinTerminal — 中文文档

> 完整中文文档正在从原始 README 整理迁移。当前主 README 将作为国际开源项目入口；原有中文功能说明不会从项目历史中丢失。

FinTerminal 是一个基于 FastMCP 的本地金融研究与数据分析工具，核心工作流是：

**读取本地/市场数据 → 分析与可视化 → 自然语言研究 → RAG/Agentic Research → 数据来源与变更追溯。**

项目提供精简的 MCP 工具接口，同时包含 Windows 桌面应用、统计分析、研究报告、实时行情、知识库、策略回测、插件系统和数据可信链等能力。

## 主要能力

- CSV / Excel / Word / PDF / 文本与图片数据读取
- 27+ 图表与交互式可视化
- 描述统计、相关、回归、稳健标准误、VIF、事件研究、DID 等分析
- RAG 混合检索与引用溯源
- Agentic 金融研究报告
- 实时行情、K 线、技术指标与时序预测
- SHA-256 数据链与 RFC3161 可信时间戳锚定
- Windows Electron 桌面应用
- 可扩展数据源、分析与图表插件

## 当前状态

FinTerminal 仍处于早期开发阶段。接口、打包方式和部分研究能力可能继续调整。欢迎通过 GitHub Issues 提交 bug、功能建议和使用反馈。
